What's Inside

Every tab, at a glance

Start Here & Quick Reference — the big picture, the project lifecycle, golden rules, and a one-page cheat sheet for picking a model, picking a metric, and talking about results clearly.

Learning Roadmap — what to know and why, from probability and SQL through machine learning to generative AI and MLOps, with practice tasks for each area.

Keeping It Current

Fundamentals are stable; AI tooling moves fast

The workbook separates timeless fundamentals (statistics, model assumptions, evaluation metrics) from fast-moving AI tooling (specific model names, context windows, pricing). For anything in the second category, it's a starting map, not a spec sheet — I check current official docs before quoting exact numbers.

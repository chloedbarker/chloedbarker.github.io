Texas Water Quality Project

Designed and implemented a normalized relational database (64 tables, 3NF) for Texas groundwater quality data spanning 20+ years across 254 counties. Integrated MySQL with Python for ETL workflows, performed geospatial analysis using GeoPandas, and created interactive choropleth maps with Folium to identify contamination hotspots for public health research.

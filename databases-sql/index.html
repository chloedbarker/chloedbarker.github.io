Project

Texas Water Quality Database

Designed and implemented a fully normalized relational database (64 tables, 3NF) for Texas groundwater quality data spanning 20+ years across all 254 counties. Integrated MySQL with Python for ETL workflows, performed geospatial analysis using GeoPandas, and created interactive choropleth maps with Folium to identify contamination hotspots for public health research.
